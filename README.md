# PZ-Stuff

Mods and patches by MKev for Project Zomboid Build 42.

- [I Know It!](Mods/IKnowIt/README.md)
- [Patches](Patches/README.md) — overview of MKev's Modpatcher, MKev's Modpatch Installer, MKev's Server BootPatch, and MKev's Linux-Guard
- [MKev's Modpatch Installer](Modpatch-Installer/README.md) — current release **v1.33**: all-in-one dedicated-server and client setup (ModPatcher 1.3.2, server kit, Server BootPatch 1.1.2, Linux-Guard 1.0.0, optional client RAM)
- [MKev's Modpatcher](Patches/ModPatcher/README.md) — runtime compatibility patch
- [MKev's Server BootPatch](Patches/Server-BootPatch/README.md) — boot-log script fixes (1.1.2, fixes bundled, also for Linux servers; standalone zip)
- [MKev's Linux-Guard](Patches/Linux-Guard/README.md) — optional `start-server.sh` for Linux dedicated servers: fixes mod files Linux does not find because of upper/lower case (lowercase links, nothing renamed)

Older installer packages are in [Patches/Patch-Installer](Patches/Patch-Installer/README.md).
