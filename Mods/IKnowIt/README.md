# I Know It!

Media tracker for Project Zomboid Build 42 (singleplayer and multiplayer). Author: **MKev**.

The mod was renamed from I Knew It!. Mod id `iknowit`, current version **1.02** (`versionMin` 42.21). Languages: English, German, Traditional Chinese.

It marks books, magazines, flashcards, VHS tapes, CDs and other media with icons for reading status (red = not readable, yellow = readable, green = already read). Skill books show whether they have been studied, and a studied skill book gives an XP boost. A studied skill book can be looked up once, from the main inventory, for a one-time XP drop. Media that teaches something shows a light-bulb icon. The mod also adds title prefixes (`[Skillbook]`, `[Skill]`, `[Recipe(s)]`) and a symbol legend in the tooltip. Easy Picking takes items directly from bags inside closets, corpses and vehicles.

Workshop: [I Know It! (3836594593)](https://steamcommunity.com/sharedfiles/filedetails/?id=3836594593).
